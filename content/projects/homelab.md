A five-node Kubernetes cluster on Intel NUCs running Ubuntu, with Tailscale for remote access and NAS-backed persistent storage. It’s my hands-on space for running services and learning how distributed systems fit together.

Private Git repositories and Docker automation support a personal CI/CD pipeline for builds and deployments. I’m developing an Ansible framework to codify provisioning, cluster bootstrap, and container deployment workflows.
